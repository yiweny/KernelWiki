## Summary

Adds an **SM103 (B300/GB300) grouped block-scaled GEMM** CuTeDSL kernel: a persistent kernel that dispatches multiple independent block-scaled GEMMs (different M/N/K) in one launch. Fills the gap where upstream had SM100 grouped + SM103 dense but no SM103 grouped kernel.

## Design

- **SM103 internals**: 7-warp layout with a **dedicated scale-factor TMA warp** (warp 6) separate from the A/B TMA warp (warp 5); MXF4/NVF4 ops; hand-unrolled MMA mainloop.
- **SM100-style grouped scheduling**: `StaticPersistentGroupTileScheduler` with per-group tensormap updates via shared memory.
- Primary example path:
  `examples/python/CuTeDSL/cute/blackwell/kernel/blockscaled_grouped_gemm/sm103_grouped_blockscaled_gemm.py`

## Kernel Relevance

Reference implementation for MoE / multi-shape NVFP4 GEMM on GB300: combine Ultra dense blockscaled mainloop with grouped persistent scheduling and an extra TMA warp for scale factors.
